# MAGI Consensus Engine

Асинхронная мультиагентная система, вдохновленная суперкомпьютером MAGI из Neon Genesis Evangelion. Три агента с разными характерами одновременно оценивают ваш запрос и голосуют, а арбитр выносит решение по большинству в 2 из 3. Интерфейс работает в терминале на Textual.

## Агенты

Melchior-1 это ученый, холодный и логичный, температура 0.1. Balthasar-2 это мать, осторожная и заботливая, температура 0.4. Casper-3 это женщина, импульсивная и эмоциональная, температура 0.8.

Каждый агент возвращает JSON с именем, голосом APPROVE или REJECT, уверенностью от 0 до 1 и обоснованием не длиннее трех предложений. Если модель ответила мусором, агент воздерживается, а итог считается по остальным голосам.

## Установка

Нужен Python 3.11 или новее и любой OpenAI совместимый сервер, например Ollama.

```bash
pip install -r requirements.txt
cp .env.example .env
```

## Запуск модели

По умолчанию используется легкая модель Qwen. Запустите сервер Ollama в одном терминале.

```bash
ollama serve
```

И скачайте модель в другом.

```bash
ollama pull qwen2.5:3b
```

## Запуск проекта

```bash
python src/main.py
```

Можно сразу передать запрос.

```bash
python src/main.py "Should we launch Unit-01?"
```

Enter отправляет запрос, Ctrl+L сбрасывает экран, Esc возвращает фокус в поле ввода, Ctrl+Q закрывает программу.

## Настройка

Все параметры лежат в файле .env. MAGI_BASE_URL задает адрес сервера, MAGI_API_KEY ключ, MAGI_MODEL модель для всех агентов. Для отдельного агента можно задать свою модель через MAGI_MELCHIOR_MODEL, MAGI_BALTHASAR_MODEL и MAGI_CASPER_MODEL. Для vLLM укажите адрес http://localhost:8000/v1 и имя вашей модели.

Если ответов приходится ждать долго, увеличьте MAGI_TIMEOUT_S. Если модель слабая и часто ломает JSON, возьмите побольше, например qwen2.5:7b.
